# Next Services List App

Приложение для выбора дополнительных услуг с подсчётом стоимости.

## Стек
- Next.js
- TypeScript
- Redux Toolkit
- Tailwind CSS

## Установка и запуск
npm install
npm run dev

## Функциональность
- Отображение списка услуг
- Добавление / удаление услуг
- Подсчёт количества и суммы
